# ProofPick（プルーフピック）

商品選択の「根拠」を証明する AI 買い物代行基盤。
第4回 デジタル学園祭「全国情報教育コンテスト（全情コン2026）」／第1回 愛知県大会 応募作品。

- 理想：誰でも AI ロボを安心して走らせられる社会（インフラ分離）
- 核心：「なぜその商品を選んだか」を証明できること
- 落とし込み：ブラウザで動くデモ（`html/demo.html`）
